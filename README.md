## The global green energy report

## project overview

This repository contains the technical report for the global green energy use.
it is to provide a comprehensive analysis of green energy consumption world wide

## current features

**navigation** a header section with internal links for easy navigation
**methodology section** Detailing the methods used in data collection
**results section** showcasing live reults of data collection
**recomendation section** to show ways in which we could better global green energy consumption

**language** HTML5
